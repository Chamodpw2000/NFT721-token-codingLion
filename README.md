# Coding Lion NFT JSON Host

This project hosts the Coding Lion NFT metadata JSON for public access via Vercel.

## How to deploy

1. Push this folder to a GitHub/GitLab/Bitbucket repository, or use Vercel CLI.
2. Deploy on Vercel (https://vercel.com/):
   - Import your repository, or
   - Use the CLI: `vercel`
3. Your JSON will be available at:
   `https://<your-vercel-project>.vercel.app/codingLion.json`

## Files
- `codingLion.json`: NFT metadata
- `vercel.json`: Vercel configuration
